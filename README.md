# Corral

Entorno local de desarrollo PHP y Laravel para macOS, Linux y Windows.

Este repositorio solo publica las versiones de Corral. El código fuente no está aquí.

## Descarga

Descarga el instalador desde [Releases](https://github.com/manuelcardona0228/corral_php/releases/latest).

Las versiones de macOS todavía no están notarizadas por Apple, así que macOS puede bloquear la app en otros equipos.
